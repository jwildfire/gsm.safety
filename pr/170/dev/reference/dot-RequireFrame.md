# Stop unless the object is a data.frame

Stop unless the object is a data.frame

## Usage

``` r
.RequireFrame(df, strName)
```

## Arguments

- df:

  Object to check.

- strName:

  `character` Name the reader has to act on — the mapped domain the
  metric declares, not the parameter it arrived in.

## Value

`NULL`, invisibly. Called for the error.
