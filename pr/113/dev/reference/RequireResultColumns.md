# Require a data frame with the named columns

Require a data frame with the named columns

## Usage

``` r
RequireResultColumns(df, chrCols, strName = "dfResults")
```

## Arguments

- df:

  The object to check.

- chrCols:

  `character` Column names that must be present.

- strName:

  `character` Name of the argument, for the message.
