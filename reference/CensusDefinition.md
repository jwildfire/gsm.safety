# The definition row for one metric ID, or nothing

The definition row for one metric ID, or nothing

## Usage

``` r
CensusDefinition(dfMetrics, strID)
```

## Arguments

- dfMetrics:

  `data.frame` The metric definitions.

- strID:

  `character` A metric's short ID, e.g. `"saf0004"`.

## Value

`data.frame` of zero or one row.
