# A short, readable list of participant IDs for a warning

A short, readable list of participant IDs for a warning

## Usage

``` r
.NameParticipants(chrIDs, nMax = 10L)
```

## Arguments

- chrIDs:

  `character` Participant IDs.

- nMax:

  `integer` How many to name before summarising the rest.

## Value

`character(1)`.
