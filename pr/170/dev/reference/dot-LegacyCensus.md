# The `Census` table

The `Census` table

## Usage

``` r
.LegacyCensus(dfFigures)
```

## Arguments

- dfFigures:

  `data.frame` From
  [`Report_CensusFigures()`](https://jwildfire.github.io/gsm.safety/dev/reference/Report_CensusFigures.md).

## Value

`data.frame` with `Label`, `Value`, `Denominator` and `Group`.
