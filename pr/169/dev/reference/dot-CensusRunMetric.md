# One metric, run and keyed to the reporting model

One metric, run and keyed to the reporting model

## Usage

``` r
.CensusRunMetric(lWorkflow, lDomains)
```

## Arguments

- lWorkflow:

  `list` One metric definition.

- lDomains:

  Named `list` of the mapped domains.

## Value

`data.frame` of the rows it published, or `NULL`.
