# The census report's own settings

Read from `inst/workflow/4_modules/safety_census.yaml`, so the sections,
the person-time metrics and the days-per-year the page presents are the
ones this payload presents. Two readers of the same figures cannot
disagree about which of them are published in days.

## Usage

``` r
.CensusReportSettings()
```

## Value

`list` of settings.
