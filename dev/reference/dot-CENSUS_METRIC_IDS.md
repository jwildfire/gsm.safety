# The census metrics `SafetyCensus()` runs

One list, written out rather than derived, so it cannot contain the same
metric twice. `tests/testthat/test-SafetyCensus.R` asserts that it is
the same set the census report's own settings name — a metric added to
the page and not here would be a figure the report shows and the payload
lacks.

## Usage

``` r
.CENSUS_METRIC_IDS
```

## Format

An object of class `character` of length 12.
