# One presented figure, or `NA` where the metric published none

One presented figure, or `NA` where the metric published none

## Usage

``` r
.CensusFigureValue(dfFigures, strID, strCol)
```

## Arguments

- dfFigures:

  `data.frame` From
  [`Report_CensusFigures()`](https://jwildfire.github.io/gsm.safety/dev/reference/Report_CensusFigures.md).

- strID:

  `character` A metric's short ID.

- strCol:

  `character` Column to read.

## Value

`numeric(1)`.
